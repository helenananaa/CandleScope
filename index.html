策略回测

导入数据或直接使用当前图表，运行策略后检查每笔交易、权益、回撤和参数。外部量化模型也能接入，由 CandleScope 负责行情、撮合与账户。

  • Python以 Python 包运行策略，运行环境相互隔离。
  • Pine通过解释器插件运行 Pine 策略。
  • 外部模型用 SDK 接入你的模型，每一个决策都有记录。

K 线回放

在历史里练手，持仓和真的一样。

所有商品共享同一个时钟和模拟账户。任意加仓、减仓、开平仓或反手，还能同时持有多个商品。随时暂停、存档、复盘，或从任意一根 K 线分叉重来。

  • 真实的持仓逻辑均价、部分平仓与反手，一样不少。
  • 多商品同时持仓所有商品按同一个时钟推进。
  • 可恢复存档训练进度随时保存、随时继续。
  • 复盘与分叉平均 R、MAE/MFE、持仓时长，或从任意节点重来。

模拟盘与交易日志

实时模拟盘，记录你的成长历程。

限价、止损与括号单在实时行情上撮合。只读同步你的交易所账户。成交会自动归并成一笔笔交易——写下计划、复盘和标签，看着数据一点点变好。

  • 实时撮合模拟委托按实时 1 分钟 K 线撮合，重启后自动补算。
  • 交易所同步只读同步持仓、成交并对账（目前支持 OKX）。
  • 交易日志按标签统计胜率、盈亏比、R 期望值与最大回撤。

警报

警报不限数量，逻辑想多复杂都行。

用 AND、OR、NOT 嵌套组合价格与指标条件——上穿、下穿、区间、涨跌幅——触发时还能看到是哪一条成立的。

  • 任意嵌套条件组层层嵌套，价格与任意指标都能用。
  • 丰富的比较方式大于、小于、上穿、下穿、区间内外、涨跌幅。
  • 多种送达方式应用内、浏览器通知、声音，或带签名的 Webhook。

      当前范围与限制
      • 回放与模拟盘使用模拟委托，不会向交易所发送真实订单；交易所账户同步为只读，目前支持 OKX。
      • 历史深度与高级市场视图（盘口、订单流、合约信息）取决于所选交易所或数据提供商能提供的数据。
      • 标准工作区默认最多四张图；16 图与多窗口布局（最多 64 张图）需手动开启。
      • Pine 兼容覆盖已支持的子集；第一方 Pine 插件包目前面向 Windows + CPython 3.12。
      • 本地 MCP 仅限桌面版且默认关闭；不提供下单、脚本执行与文件访问。
      • 浏览器版运行于 Windows、Linux 与 macOS；可选桌面版支持 Windows 与原生 macOS 测试包。
