03 · 指标

指标与脚本

使用内置指标，或用 Pine 与前端 JavaScript 编写自己的指标。其他运行时可通过插件系统接入。

ema_cross.pinePine
//@version=5
indicator("EMA Cross", overlay = true)
fast = ta.ema(close, 21)
slow = ta.ema(close, 55)
plot(fast, color = color.blue)
plot(slow, color = color.orange)
plotshape(ta.crossover(fast, slow),
     style = shape.triangleup)

行情回放

回到过去，再交易一次。

在历史行情中训练：多个市场共享同一个时钟与模拟账户。随时暂停、保存、恢复；结束后复盘，或从任意一根 K 线分叉重来。

  • 同步多市场所有商品按同一个时钟推进。
  • 共享模拟账户只使用模拟委托，绝不发送到交易所。
  • 可恢复存档训练进度随时保存、随时继续。
  • 复盘与分叉回看每一个决策，或从任意节点重新开始。

快速开始

几分钟内跑起来。

后端与前端各开一个终端，然后在浏览器里打开工作台。

  • Python 3.11+ （推荐 3.12）
  • Node.js 20+
  • npm 10+
  1. 克隆仓库
  2. 启动后端API 运行在 127.0.0.1:18080
  3. 启动前端在第二个终端里
  4. 打开工作台127.0.0.1:15173
# 终端 1 —— 后端
$ git clone https://github.com/helenananaa/CandleScope.git
$ cd CandleScope/backend
$ python3 -m venv .venv
$ source .venv/bin/activate
$ python -m pip install -r requirements.txt
$ ./dev-server.sh
# 终端 2 —— 前端
$ cd CandleScope/frontend
$ npm install
$ npm run dev
➜ Local: http://127.0.0.1:15173/

当前范围与限制
  • 回放使用模拟委托，不会向交易所发送真实订单。
  • 高级市场视图取决于所选交易所与市场提供的数据。
  • 标准工作区最多支持四张图，更大容量的布局需手动开启。
  • 第一方 Pine 插件包目前面向 Windows + CPython 3.12，Pine 兼容覆盖已支持的子集。
  • 浏览器版运行于 Windows、Linux 与 macOS；可选桌面版支持 Windows 与原生 macOS 测试包。
