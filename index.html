指标

指标不设上限，Pine 指标直接迁移。

一张图上想叠多少指标都行。Pine 解释器插件直接运行你现有的 Pine 指标，也可以用 JavaScript 写新的。

  • Pine 解释器插件迁移指标，无需重写；引擎是开源的 pine-compat-runtime。
  • JavaScript 指标在前端编写属于你的指标。
  • 内置指标均线、震荡指标、成交量等开箱即用。
ema_cross.pinePine
//@version=5
indicator("EMA Cross", overlay = true)
fast = ta.ema(close, 21)
slow = ta.ema(close, 55)
plot(fast, color = color.blue)
plot(slow, color = color.orange)
plotshape(ta.crossover(fast, slow),
     style = shape.triangleup)

警报

警报不限数量，逻辑想多复杂都行。

用 AND、OR、NOT 嵌套组合价格与指标条件——上穿、下穿、区间、涨跌幅——触发时还能看到是哪一条成立的。

  • 任意嵌套条件组层层嵌套，价格与任意指标都能用。
  • 丰富的比较方式大于、小于、上穿、下穿、区间内外、涨跌幅。
  • 多种送达方式应用内、浏览器通知、声音，或带签名的 Webhook。

    02

    练习

    无风险地交易——在历史和实时行情里练手。

    K 线回放

    在历史里练手，没有后见之明。

    所有商品共享同一个时钟和一个合约级模拟账户。任意加仓、减仓、反手，同时持有多个商品。挑战模式从一个随机时刻开始，你不知道是哪一天。

    • 沙盒或挑战随时调整，或锁定规则、盲抽起点。
    • 合约级账户杠杆上限、手续费、历史资金费率；双向持仓时多空两腿各有保证金、强平和保护单。
    • 多商品，同一个时钟同时持有多个商品，一起向前推进。
    • 存档、复盘与分叉平均 R、MAE/MFE、持仓时长，或从任意一根 K 线重来。

    回放 · 沙盒

    反复练一个形态

    自己选起点，随时调整资金、手续费和杠杆；每一次改动依然有记录。

    没有后见之明

    盲抽随机起点，你不知道是哪一天。规则锁定，已经揭示的时间不能收回，结束后附一份完整性报告。

    实时模拟盘

    03

    验证

    证明想法成立——每一笔交易都能解释。

    策略回测

    在图表上回测，每一笔交易都能解释。

    在正在看的图表旁用 Python 或 Pine 写策略，点开任意一笔交易，就能看到策略做决定那一刻掌握的依据。每份结果都附带测试假设：手续费、滑点与成交模型。

    • 图上策略测试器Python 包在隔离环境中运行，Pine 通过解释器插件运行。
    • 滚动前推检验在滚动窗口上挑参数，再到没见过的数据上验证。
    • 对比与迭代2–4 个策略并排对比，保留版本，随时重跑。
    • 前向跟踪让策略从现在或过去某天起，继续跟着实时 K 线运行。
    • 你自己的模型用 SDK 接入，行情、撮合与账户由 CandleScope 负责。

    04

    复盘

    从每一笔交易里学习——从计划到复盘。

    交易日志

    每一笔交易，从计划到复盘。

    成交会自动归并成一笔笔交易。开仓前写计划，持仓中记笔记，平仓后写复盘——看着数据一点点变好。

    • 三个阶段开仓前、持仓中、平仓后，模拟与真实交易都适用。
    • 按标签统计胜率、盈亏比、R 期望值与最大回撤。
    • 回放报告平均 R、MAE/MFE 与持仓时长，每次训练另附完整性报告。
    • 交易所同步只读同步持仓、成交并对账（目前支持 OKX）。

      当前范围与限制
      • 网页版 app.candlescope.app 无需安装：看盘、回放训练与模拟盘直接在浏览器里运行，数据只保存在你的浏览器中；运行脚本策略、连接交易所账户与插件需要本地安装版。需要较新版本的 Chrome、Edge、Safari 或 Firefox，暂不支持安卓 Chrome。
      • 回放与模拟盘使用模拟委托，不会向交易所发送真实订单；交易所账户同步为只读，目前支持 OKX。
      • 历史深度与高级市场视图（盘口、订单流、强平、合约信息）取决于所选交易所或数据提供商能提供的数据。
      • 标准工作区默认最多四张图；16 图与多窗口布局（最多 64 张图）需手动开启。
      • Pine 兼容覆盖经过测试的子集；第一方 Pine 插件可在桌面版和本地安装中运行，支持 Windows、Linux 与 macOS（Apple 芯片与 Intel），网页版暂不支持。
      • 本地 MCP 与代理订阅仅限桌面版；MCP 默认关闭，不提供下单、脚本执行与文件访问。
      • 浏览器版运行于 Windows、Linux 与 macOS；可选桌面版支持 Windows 与原生 macOS 测试包。
