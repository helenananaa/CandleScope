# 预计算索引支持的区间跳跃

回放现在会在打开暂停的 BAR/HEDGE 训练时准备行情与账户索引。无交互区间不再逐根调用经纪商 reducer，也不再逐分钟写入公共标记价回执；推进保存区间引用与终点状态。准备成本和交互成本分开计量。

## 执行方式

`PreparedBarInterval` 从同一份冻结 BAR 输入准备价格范围树、源事件链前缀和每 128 个事件一个的 K 线构造状态。查询终点时恢复邻近构造状态，最多补做 127 个 builder 更新，不重放被跳过区间的账户 reducer。当前配置、源游标或源链不匹配时重新准备；准备中发现无效未来数据时只保留有效前缀，原路径在实际到达错误边界时报告错误。

账户权益索引绑定执行模型、配置、持仓与现金账本。树节点保存最高权益、最低权益，以及有先后顺序的最大回撤；合并时纳入“左区间最高权益减右区间最低权益”。因此最大回撤不以终点权益或单根 OHLC 近似。账户变化使权益索引失效，行情索引可以继续复用。

推进前通过价格索引定位首个可能触价的订单，通过公共输入索引截断资金费、规则和模拟事件。风险范围不能整体证明安全时二分缩小到可证明的前缀，再由原路径处理边界事件。重要的更低权益点可形成额外边界；不再要求记录每一个被跳过的微小回撤刷新。

一个区间提交终点 actor 检查点、终点风险投影、公共 MARK 范围回执和曲线引用。输入审计按需读取冻结归档，验证范围内全部为 MARK_INDEX、范围连续、边界哈希匹配、未越过已应用游标。源数据和真实交易没有被替换为另一份交易所高周期行情。

## 图表与曲线

`PreparedDisplay` 为冻结 BAR 的 OHLCV 建立范围树。图表尾部和历史查询在修订、范围匹配时使用它，沿用 `SourceBucketTimeMapper` 处理源周期和公开时间。它同时准备最多 20160 根已揭示前缀；超出缓存覆盖范围、未绑定修订等情况仍使用原历史查询。存在独立固定的原生高周期归档时，原生闭合 K 线的替换逻辑仍保留。

准备期间将完整基础权益序列保存为带版本的派生缓存。推进只记录所用区间；权益接口读取时才展开样本，并保留更高 source_sequence/revision 的已有值，不覆盖后续手续费或资金费更新。

前端通过 `/runs/{run_id}/prepare-index` 在打开训练阶段完成准备。这个接口不会推进时间、成交订单或修改账户。准备未命中时，推进仍可现场准备，因此首次调用耗时不能当作索引就绪后的延迟。

## 范围与兼容

当前快速路径支持暂停的单 FULL 主轨 BAR/HEDGE、空仓或单个非零持仓腿，盘口 OFF，资金费 OFF 或 HISTORICAL_EXACT，且满足已有路径依赖检查。跨风险档位或其他无法整体证明的范围会细分；多轨、双腿持仓、盘口依赖、历史精确账户等仍走原路径。索引目前每次准备最多 100000 个未来基础事件。

准备复杂度与数据量相关；已准备的跳跃主要是范围查询、少量边界工作及固定上限的 builder 补齐。曲线首次展开仍是线性工作。这里不是对所有模式、所有缓存状态作常数时间承诺。

训练 schema 从 19/20 增量升级到 21，新增 `replay_prepared_curve` 和 `replay_hedge_mark_span`。既有会话保留；回滚到旧代码需要恢复升级前数据库。新代码可以从较早有效检查点重建索引，重放已提交的 INDEXED_INTERVAL 命令。

另修复了 BOOK=OFF 强平审计错误地要求历史 L2 快照的问题；只有 BOOK_ASSISTED_REQUIRED 才要求对应的 L2 回执，已有回执仍正常验证。

## 测量和验证

本轮隔离的 1w 合成样本跳过 10046 个逐根账户事件：首次推进约 4.12 秒，提前准备约 2.83 秒后的推进约 233 毫秒。最终 actor 状态、真实现金流水和保留权益序列与参考一致。这组数字早于图表索引接入，只用于说明准备与推进的区别，不当作最终界面延迟。

最终前台 Chrome 测量使用真实前端、HTTP/WS 路由和合成冻结数据：接口约 424 毫秒；点击到游标更新约 492 毫秒，图表数据更新约 548 毫秒，双帧绘制回调约 556 毫秒。首次打开的索引准备约 4.57 秒。原始记录为 `indexed-browser-timing.jsonl`、`indexed-browser-ui-v3.json` 和 `indexed-browser-week.png`。

这是工作机单次测量，不是分位数保证。早期一次未固定前台的测量出现约 2.68 秒绘制回调延迟；原始数据保留，最终测量明确将 Chrome 置于前台。浏览器测试夹具是旧式训练创建方式，不覆盖侧栏“添加商品”目录；截图中的该提示不属于推进路径。测试没有推进用户存档。

验证覆盖多空、全仓/逐仓、空仓挂单、较晚订单/资金费暂停、首次强平边界、完整回撤、隐藏时间、旧 schema 升级、区间事务回滚、缺少最终检查点的恢复、跳跃前复盘分叉，以及图表范围与修订不匹配时回退。旧批处理路径作为独立回退继续测试。

扩展回归首次运行 829 passed，唯一失败是旧测试固定要求经过 512 根批处理；将该测试明确限定为回退路径后，40 项相关专项全部通过，覆盖了该失败项。830 个扩展回归场景已完成验证，另外 4 项最终图表检查通过（含新增的不可整除月/周组件边界）。前端 397 项回放测试、TypeScript、ESLint、构建及后端 Ruff 通过。原始失败日志保留，`indexed-qualification.json` 明确记录合并验证方式，没有将首次运行伪记为全绿。
