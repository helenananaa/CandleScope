## 修改与适用范围

1. 普通目标扫描路径此前分别提交终态 advance intent 和命令返回结果。现在同一事务提交两张表，终态收尾从两次事务变成一次。中间游标、开始意图和领域事件的持久化不变。现存的终态意图缺少返回结果时仍可恢复；失败意图不能发布成功收尾结果。相同 command ID 的命令/结果冲突会回滚整个事务。
2. 当前页面的 HEDGE 双向账户使用有序输入时钟，不经过上述目标扫描路径。其标记覆盖此前即使结果不变也更新行及时间戳。现在仍完整验证输入哈希、绑定、规则并计算账户结果，但只有 position/account/public price 中有实际变化时才 UPDATE。重复应用的无变化结果不再产生数据库行修改，更新时间表示实际投影写入时间。风险指纹检查及变化后的风险检测保持原行为。

没有降低 SQLite synchronous=FULL，也没有异步确认尚未持久化的结果。减少事务和脏页能减少遇到磁盘长尾的机会，但并不能保证每次提交延迟降低。
