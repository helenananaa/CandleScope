# 外部策略与模型连接实施合同

状态：实施中；不是功能已完成或原生验收通过的声明。

依据：用户于 2026-10-17 明确选择 BT-05 优先接入外部策略/模型，市场数据、撮合、账户和审计仍由 Host 统一负责。遵循 [回测产品合同](BACKTEST_PRODUCT_CONTRACT_zh.md) 的 `strategy-provider/1` 生命周期、已有输出种类、时钟、账户和资源门禁。

## 范围

外部程序通过当前本机 Host 的连接接口取得有界观察并提交决策。Host 不执行用户上传的模型代码，不新增任意 Python 编辑器执行权限，也不访问 manifest 中指定的网络端点。示例客户端可独立运行，并可替换其模型实现；界面负责选择数据、连接、运行、取消和读取 Host 报告。

版本一沿用默认关闭的 `BACKTEST_EXTERNAL_PROVIDER_ENABLED`。关闭时不创建连接数据库、凭据或后台任务，界面明确显示能力状态。原生启用配置的验收与默认生产配置回归分别记录。

已有 gRPC/ONNX 夹具、记录输出或表达式回退不构成这里的真实外部连接实现，不将其作为成功的替代路径。

## 不可变身份

`candlescope.external-provider/1` manifest 是数据，不包含执行入口、文件路径、网络地址或账户字段。固定提供器 ID/修订、策略或模型类别、artifact SHA-256、runtime lock、输入/输出模式、特征顺序、warmup 和状态恢复能力。当前只向外部提供完结 BAR 观察；它可以用于 BAR 回测及既有真实成交双时钟。

策略可声明 `SIGNAL`、`TARGET_POSITION`、`ORDER_INTENT`；模型只声明信号或目标。所有订单仍经过 Host 规则、资金和风险检查。外部进程没有账户、成交、权益、报告或数据库写入接口。

Host 无法证明外部进程实际采用何种训练资料、设备或算法。因此此连接固定标记 `RECORDED_OUTPUT_ONLY`，保存实际决策及状态；不根据客户端自称的算法或 seed 宣传确定性或无样本泄漏。

连接绑定不可变策略修订及选定的数据集 ID、epoch、snapshot hash。每次实际调用还定位 run、Host generation、调用序号、操作和输入 hash，不能借同一连接改用其他快照。

## 连接与凭据

1. 在选定不可变策略与数据后创建连接，生成随机能力凭据；数据库只存其摘要。
2. 连接文件保存在 Host 管理的私有目录，使用适用平台的私有文件权限。凭据只出现在该文件及显式连接交付中，不进入 manifest、运行身份、报告、决策记录、支持日志或公开导出。
3. 外部 SDK 使用连接文件访问当前 loopback Host；它不接受 manifest 指定的外部服务器。桌面动态端口通过不含凭据的当前 Host endpoint 文件发现，完整重启后可重新连接。
4. 连接只有一个有效客户端租约；同一客户端的网络重试幂等，另一个活跃客户端不得抢占。旧租约、旧客户端 generation 和已撤销凭据的响应被拒绝。
5. 外部程序先连接，再完成实际 bounded smoke 和运行；不能跳过已有 smoke 要求。断开时 UI 明确显示状态。恢复中的队列等待有效连接，不挤占其他可运行任务。

## 生命周期与恢复

沿用 `describe → prepare → warmup → step/onExecutionReport → snapshot/restore → close`。描述与预检仅解析身份和能力，不伪造模型执行结果。实际 smoke 和 Run 必须经过外部进程。

- Host 只发送 watermark 以内的观察。warmup 只能更新模型状态，不能产生可成交输出。
- SDK 为每个 run 单独创建模型实例。一个连接中的 smoke、不同 Run 和 generation 不能共享未声明的状态。
- 外部响应回显准确调用身份、输入 hash 和序号。结果及模型快照使用严格、有限的 JSON，受已有状态、消息及总存储预算限制。
- 相同调用的相同重试可回读已提交响应；不同响应、错误 generation、越权输出、未知字段和篡改 hash 必须失败，不能偷偷应用到下一根数据或另一个 Run。
- Host 持久保存实际请求、响应、状态及摘要。checkpoint 保存调用游标和模型状态；恢复时重放已记录决策，并在新调用前恢复外部模型状态，不能重复应用交易或让模型状态领先 Host 重放位置。
- JSON 使用排序键、紧凑分隔符、ASCII 转义、有限数值及 UTF-8，与 Host `canonical_hash` 一致。重复键、过深结构、不精确的大整数和超预算消息拒绝；金额及数量使用有界十进制字符串。外部输出不提供可覆盖 Host 的 output/state hash，由 Host 从校验后的内容计算。
- 外部阶段沿用 Host 的 `WARMUP` / `EVALUATION`。`TARGET_POSITION.targetExposure` 沿用现有 Host 的绝对基础币数量含义；订单使用 Host 的 snake_case 价格字段，不接受外部 order ID 或生效序号。
- 调用记录只保存决策和状态摘要。模型状态按摘要去重，保留每个 run 的当前状态及 checkpoint 固定状态，释放未固定的中间状态。逻辑字节预算与调用、响应、状态、游标在同一 SQLite 事务内更新，超限整笔回滚；该预算不是物理数据库文件大小保证。
- 客户端掉线、超时、取消、应用退出和恢复失败必须有明确终态或等待状态。沿用 Host 单步及整局预算，不通过放宽既有全局限制来让样例通过。
- 连接记录由单独的 Host SQLite owner 管理；默认关闭不创建文件，不修改旧账户/报告记录。取消或撤销只能关闭连接和未完成调用，不改写既有交易真值。
