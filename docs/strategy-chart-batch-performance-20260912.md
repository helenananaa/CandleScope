# 策略回测：受限图表策略批量计算

本轮在 `codex/strategy-replay-performance` 工作区实现受限图表策略快路径，接续此前未提交的优化。没有提交、推送或部署。

## 结果

以下都是本机 Windows、同一基准入口、10 万根合成 K 线、EXECUTION_REALISM_V2 的完整回测，包含工作进程启动、撮合、成本敏感性分析、检查点及报告保存。不是仅指标循环的时间，也不包含下载、排队或浏览器显示。

| 相邻开关对照 | 批量关闭 | 批量开启 | 耗时减少 |
|---|---:|---:|---:|
| 图表 SMA 3/5 | 10.294 s | 8.247 s | 19.9% |
| 图表 RSI 14 | 23.026 s | 12.549 s | 45.5% |

对应 `output/strategy-batch-20260912/repeat-{SMA,RSI}-{0,1}.json`。关闭批量的这组对照仍包含本轮“解释前缀封闭后不再构造丢弃行”的公共优化，因此表内只计算批量路径的收益。

补完共享超时预算后的最终源码再测：SMA **7.352 s**、RSI **11.405 s**，见 `final-SMA.json` 和 `final-RSI.json`。此前实现还测得 SMA 12.272 s、RSI 14.792 s，不能只挑较快样本宣称稳定达标。中间版本 SMA 6.922 s、RSI 19.526 s 等也保留在证据目录。**尚未稳定满足全部场景 10 万根低于 10 秒的目标，任意 Python 脚本本轮没有新增加速。**

所有已完成样本均校验报告哈希：SMA 为 795 笔成交、1001 权益点、3,793,115 报告字节；RSI 为 796 笔成交、1001 权益点、2,405,915 字节。字节数是基准现有 JSON 编码口径。

最早两个 `baseline-sma.json`、`batch-sma.json` 是 LEGACY_DEFAULT 执行模型，包含 10 万权益点，耗时 20.285/21.304 s。它们不是 V2 的同口径对照，保留但不混入上述收益。

## 实现边界

- 只接入整个回测由父进程监督的工作进程中，由宿主创建的精确 `ChartPyneStrategyProvider` 类型。任意 Python、插件、自定义 provider 子类、流式输入及非 BAR 执行不走此路径。
- 每批最多预计算 128 根的指标和条件分支。临时状态不含账户和执行反馈，也不会暴露给用户脚本。实际账户、风控、撮合、解释、会话序号和水位、检查点继续逐根推进。恢复仅使用已消费状态，剩余预计算可丢弃重算。
- RSI 缓存相邻涨跌变化，但继续按原窗口顺序进行 Decimal 求和及除法；没有改为 Wilder RSI，也没有使用可能改变舍入结果的滚动总和。最高/最低使用单调队列，相等时保留最早值及其数值拼写。SMA 保留原求和顺序。
- 预编译条件比较，避免每根构造历史引用与比较表。旧规划器只消费目标值、不持久化 provider 输出哈希，因此可直接消费私有目标负载，省去未使用的中间哈希。版本化风控规划器仍获得完整 StrategyOutput 及相同哈希。
- 完整输出哈希缓存已消费 OHLC 的字符串表示，使用上一轮已验证的原生 ASCII JSON 编码器；缺少原生模块或整数超出其范围时保留标准编码路径。不会创建伪造的 provider wire receipt。
- 交易解释沿用原来的行数和字节限额。前缀已经封闭时，继续累计决策序号、同时间序号及遗漏计数，省去不会保存的行构造；不减少已保存明细。
- 额外指标窗口及批次槽位合计超过 65,536 时回退；复杂输入值也回退。支持本地快照附带的整数开盘/收盘时间字段。
- 批量计算期间仍发布逐次计算截止时间，父进程继续监督总时间和取消。坏的未来数据作为待消费错误保存，到对应事件边界才抛出。

开关：`BACKTEST_CHART_BATCH_ENABLED=0` 禁用批量路径。公共的解释前缀优化仍有效。

## 验证

新增测试覆盖每根输出、快照、状态哈希、交易解释完全相等；批次中途恢复；预热；重复时间戳；未来坏数据和倒退水位；Decimal 精度 6/28、大数、小数、负数、零与不同尾零；相等极值；非合格输入回退；解释已封闭时的计数。独立复制数据库，实际 spawn 开关 A/B 比较 SMA、RSI、突破策略的整份 result/report，覆盖旧规划及版本化风控拒单。

后端相关回归 186 项通过、4 条警告，见 `output/strategy-batch-20260912/regression.xml`。补充分段计算共享同一个逐步超时预算的测试后，重新运行批量路径、工作进程、运行时与恢复测试，53 项通过、4 条警告，见 `final-guards.xml`；两组用例有重叠，不相加。语法编译和 diff whitespace 检查通过。未声称完成生产页面、任意第三方脚本或其他操作系统的性能验收。

另保留 `profile-rsi.txt/.json/.pstats`：实际 1 万根子进程剖析中，策略回调累计约 0.474 s，主服务 1.332 s；策略之外的撮合、敏感性循环、检查点和编码仍占显著时间。这是带 profiler 的定位样本，不能作为端到端延迟承诺。

## 复现

在该 worktree 的 backend 目录执行：

```powershell
$env:BACKTEST_CHART_BATCH_ENABLED='1'
H:/program/CandleScope/.venv/Scripts/python.exe -m scripts.benchmark_strategy_bar_audit --bars 100000 --strategy RSI --v2 --output ../output/strategy-batch-20260912/reproduction.json
```
