# 持仓快照规范编码复用

在上一轮持仓波次合并基础上，本轮缓存不可变已闭合 BAR 的规范 JSON 字节，并在构建 BAR builder 和 broker 哈希时复用已编码的子树。实际快照仍是原来的独立 dict/list，哈希算法、字段、排序和持久化格式不变。

缓存只用于 builder 持有的冻结标量 ReplayDisplayBar，以对象身份匹配，容量不超过已保留的闭合 K 线窗口；恢复或重置清空缓存。活动 K 线与其他可变账户字段每次重新编码。普通调用者修改返回快照不会污染缓存。Trade builder 和自定义 builder 继续使用原快照路径。

`_canonical_object_bytes` 是内部组合器，仅接受调用方自己从确切字段值生成的规范编码。它不是接收外部原始 JSON 的入口；未缓存字段仍经过原有规范化与浮点禁用检查。
