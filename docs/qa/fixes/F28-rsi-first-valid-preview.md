# F28：RSI 首次满足预热条件的实时值缺失

日期：2026-09-08。来源：指标数学边界补查。

RSI(period) 需要 period+1 根价格、共 period 个变化量。已有 period 根确认 K 线时，正在形成的下一根已足够产生第一个 RSI；原 update_partial 用 count <= period 直接返回空值，因此相同 OHLC 在实时预览与收盘计算之间不一致。

修复：该边界用已有初始化涨跌变化和当前变化计算初始平均涨跌；不推进确认状态。更早的数据仍返回空值，完成预热后的 Wilder 递推不变。

新增独立预期值测试覆盖周期 2/14/100、单调上涨/下跌/交替涨跌，合计 9 组；验证预热不足、重复实时更新不污染状态、收盘结果以及全量初始化一致。修复前 9 组全部失败，修复后连同 API、桥接、批量计算和修订回归共 89 项通过。生产 dist 未变，包含后端修复的 Mac arm64 应用重新打包成功。

证据：output/user-audit-20260908/rsi-preview-before.log、rsi-preview-tests.log、rsi-preview-package.log。

本项不声称解释了原 O02 市场切换时的全部瞬态，也未改变 RSI 在完全横盘等其他边界的既有约定。未用 GUI 人工等待第 15 根实时 K 线收盘；数值证据来自确定性计算生命周期测试。
