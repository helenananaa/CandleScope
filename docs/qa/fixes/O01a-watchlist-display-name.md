# O01a：搜索菜单与侧栏对同一列表使用不同名称

## 复核结果

2026-09-08 在生产预览中搜索 OKX BTC-USDT-SWAP，右键后连续点击 `Watchlist +`，关闭搜索，侧栏由“自选 0”变为“自选 1”。刷新页面后商品仍存在，随后显示报价。因此本次没有复现原审计 O01 怀疑的添加写入失败，不修改添加逻辑。

确认的问题是默认列表命名不一致：搜索菜单直接展示存储名 `Watchlist`，侧栏对同一个默认列表显示本地化名称“自选”，用户难以确认添加目标。

## 修复

提取现有侧栏名称规则，搜索右键菜单和已加入提示复用该规则。仅对 id 为 `default` 且原名为 `Watchlist` 的默认列表本地化；自定义列表以及用户改过的默认列表名称均原样保留，不迁移或重写存储数据。

## 验证

- 单元测试覆盖中文默认名、英文默认名、自定义同名列表、已重命名默认列表。
- TypeScript、针对性 ESLint、`git diff --check` 通过；生产构建成功。
- 电脑操控生产构建：添加并刷新仍显示“自选 1”；再次打开同一商品右键菜单，显示禁用的“自选 ✓”，与侧栏一致。
- 证据：`output/user-audit-20260907/evidence/O01-added.*`、`O01a-persisted.*`、`O01a-menu.*`；构建及类型日志为 `O01a-*.log`。

## 边界

本轮 GUI 复核 OKX 单个商品，不声称 Binance、列表排序、重命名、移除全部通过。测试加入的 BTC-USDT-SWAP 保留在本地自选中，原收藏未改动。收藏与自选概念的整体说明不在本次名称修复范围。浏览器生产构建验证不代表原生安装包验证。
