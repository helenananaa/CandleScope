# F34：自选列表缺少按表头排序

日期：2026-09-08。

## 问题与修复

原生发行版中加入 BTC、ETH、SOL 后点击涨跌幅表头，列表仍保持添加顺序。源码表头为无事件的 span，只有手工拖动逻辑，没有数值排序入口。

商品、最新价、涨跌和涨跌幅表头改为可键盘操作的按钮。首次点击升序、再次点击降序，分别排列各个列表，保留分组；报价缺失、无效或订阅关闭的项目在数值排序时放末尾，相同值保留原顺序。使用与行显示相同的 daily_change/daily_change_pct 优先级和回退公式。

排序按点击时的报价快照执行，结果写入现有自选存储。报价更新不会自动移动行，按钮提示明确说明这一行为。拖动开始后清除上次排序箭头。未改变存储格式。

## 验证

- 31 项自选测试通过，新增覆盖数值升降序、百分比与涨跌口径、缺失值、关闭订阅、无效数值、稳定顺序、分组和输入不可变性。
- TypeScript、针对修改文件的 ESLint、生产构建及 Mac arm64 原生打包通过。
- 原生界面价格升序 SOL/ETH/BTC，降序 BTC/ETH/SOL；涨跌幅按当时数值升序 BTC/SOL/ETH，降序 ETH/SOL/BTC。刷新和完整退出重启后仍为 ETH/SOL/BTC。
- 日志与截图位于 `output/user-audit-20260908/watchlist-sort-*`、`watchlist-price-{asc,desc}`、`watchlist-pct-{asc,desc}`。
