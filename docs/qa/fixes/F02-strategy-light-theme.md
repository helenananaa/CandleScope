# F02 策略区域浅色主题可读性

问题：卡片、诊断区、结果区域背景写死为深色，而文字使用随主题变化的深色前景；模板 hover 及状态色也仅适配深色。

修复：策略测试器和入口采用局部语义状态色，浅色下使用深蓝/青/绿/红/棕前景；卡片、hover、边框使用现有主题变量。辅助说明使用可读的次级文字色。不更改回测逻辑、数字格式或布局。Monaco 源码区保留自身完整深色语法主题，其外部标题/诊断跟随应用主题。
