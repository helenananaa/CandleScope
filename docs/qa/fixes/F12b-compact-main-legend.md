# F12b 窄图主行情信息占位过多

原因：信息头根据浏览器宽度设置固定预留区域；双图及四图中的实际图表单元更窄，OHLC、成交量、涨跌和振幅不断换行，压住 K 线。

修复：跟随单张图表实际宽度切换布局。小于 600 CSS 像素时显示收盘价和涨跌幅，指标区限制为一行；600～899 像素收起成交量与振幅；更宽图表保留完整字段。完整行情和叠加指标数值保留在辅助功能名称、原生悬停提示中，信息头可键盘聚焦。显示裁切不改变数据或十字光标取值。

验证：相关 ESLint、TypeScript、Production build、git diff --check 通过。电脑操控生产构建验证双图、双图加底部策略面板：行情与均线仅占两行；放大单图后恢复 O/H/L/C 和绝对涨跌，再恢复双图后自动收起。辅助功能文本包含被收起的开高低、成交量、振幅和 MA 值。证据 output/user-audit-20260907/evidence/fix-F12b-narrow.png、fix-F12b-short.png、fix-F12b-expanded.png、fix-F12b-restored.txt；构建与类型检查日志同目录 fix-F12b-*.log。

边界：本轮实际验证窄与中等宽度，没有覆盖超过 900 CSS 像素的界面截图，也未验证原生悬停气泡弹出时机。F12 的最小可读副窗格高度仍待处理。
