# F13b 首次转换到稀疏合成图产生大面积空白

原因：视野迁移原样保留源逻辑跨度。例如 120 列范围映射到 8 根合成柱时，恢复范围为 -113～7，绝大部分画面为空。原测试曾明确要求此结果，现按用户审计的可读性要求修正。

修复：跨表示或显式跨数据集迁移到 derived-ordinal 时，若跨度超过可用合成柱数量，则缩小到可用数量，并按比例保留锚点屏幕偏移，不沿用不匹配的柱间距。同一表面的精确缓存恢复仍保留原缩放，不批量重置已有用户视野。
