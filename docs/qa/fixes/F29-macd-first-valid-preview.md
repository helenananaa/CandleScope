# F29：MACD 快慢线与信号线首次有效值的实时预览

日期：2026-09-08。

MACD 实时预览只使用已经存在的 EMA 状态，因此当前 K 线刚好满足慢线初始平均或信号线初始平均条件时，预览缺失，对应收盘值却有效。确定性测试 fast=3/slow=5/signal=3 在第 5、7 根复现，修复前 2 失败、7 通过。

修复：实时路径在初始平均边界使用确认数据的累计和及当前值生成临时 EMA；信号线同样处理首次满足周期的 DIF。没有修改确认状态、预热不足行为或既有柱值 2*(DIF-DEA) 约定。

独立参考以初始简单平均和指数权重展开计算 EMA，覆盖九个长度，验证每个输出、重复预览无污染、收盘和全量初始化。相关回归共 98 项通过；production dist 未变，更新后端的 Mac arm64 应用打包通过。

证据：output/user-audit-20260908/macd-preview-before.log、macd-preview-tests.log、macd-preview-package.log。此项是计算生命周期缺陷，不等同于已解释 O02 的全部市场切换瞬态；没有使用 GUI 等待实时预热边界。
