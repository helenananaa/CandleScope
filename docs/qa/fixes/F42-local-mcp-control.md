# F42：桌面 AI MCP 控制入口

状态：核心功能已实现，第 34 版 ARM64 生产原生验收通过。不能把本文件视为全项目验收通过。

## 原问题与实现范围

原产品没有可配置、可撤销的 AI MCP 入口。新增桌面设置 → AI MCP，提供关闭、只读、控制、连接配置和本次会话最近 50 次调用记录。启动默认为关闭，显式启用时生成仅本进程有效的凭据；切换权限或撤销会关闭旧监听、会话和请求。

当前工具：

- `candlescope_list_views`：列出已打开的行情/回放图表，返回明确的窗口、图表和不透明版本。
- `candlescope_read_view`：读取配置、图型、周期、指标数量、联动组及回放运行状态。`readiness=configured` 只说明配置已存在，不代表数据已完成加载。
- `candlescope_set_chart`：指定窗口/图表、预期版本和操作 ID，切换周期/图型；复用现有联动规则并返回实际受影响图表。React 提交以后才生成回执。
- `candlescope_replay_control`：对当前拥有控制权且准确绑定的活动回放图表暂停/推进一根显示周期柱。推进的是多商品共享金融时钟，可能触发现有模拟订单。接口不提交新订单，不自动抢占控制权。

不提供脚本执行、文件访问、订单提交、未揭示行情或时间戳。策略研究页尚未注册为控制目标。图表配置接口与行情加载完成之间有明确边界，不能把成功配置的回执当作数据加载性能验收。

## 传输、权限与一致性

采用 [MCP 2025-06-18 Streamable HTTP](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports) 的 JSON 响应方式；仅监听 `127.0.0.1` 随机端口。校验精确 Host、Bearer、协议版本和会话，拒绝带 Origin 的网页跨源调用。可信桌面页面通过既有 Electron 发送者校验管理权限。

变更必须提供 `expectedRevision` 与 `operationId`。相同会话内完全相同的重试共享结果；同 ID 不同参数拒绝。超时/取消已接收的推进不会宣称金融时钟已回滚，而是报告结果未知，要求重新读取状态。目标窗口关闭或导航会注销目录、拒绝迟到回复；禁止自动回落到另一张活动图。

限制：正文 64 KiB、结果 2 MiB、16 个会话/并发请求、每分钟 240 个已鉴权请求、每会话 256 个写操作。达到操作上限需新会话并重新读取版本。审计只记录工具、目标 ID、结果和耗时，不保存凭据、价格、脚本或调用参数。

## 原生验收步骤（第 34 版均完成）

1. 生产启动保持关闭；设置可见并能开启只读。
2. 真实 HTTP 客户端握手、发现/读取图表；只读模式拒绝变更。
3. 本次隔离资料允许控制后，指定图表切换周期和 Renko；核对实际画面及受影响图表。
4. 旧版本拒绝、相同操作重试不重复执行；回放推进一次并核对原生尾部和金融账本。
5. 撤销后原客户端无法访问；应用重启后仍关闭。
6. 保存脱敏证据，凭据不写入验收报告。
