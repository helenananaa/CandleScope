# F08b 旧成交持续显示实时

原因：状态标签只订阅连接状态，旧近期快照进入 live 后即使没有后续成交也一直显示实时。

修复：独立观察未筛选成交流中最大的成交时间，每秒检查一次；超过 60 秒显示“60 秒无新成交”，悬浮及无障碍提示提供最新成交日期时间。连接错误、重连、缺口等状态优先，不把无成交推断为断线。整批取最大时间避免按成交 ID 排序时末尾时间回退。该检查只在 live 状态启动，卸载或状态改变清理定时器。

验证：

- 14 项成交相关测试通过，覆盖 60 秒边界、旧数据、新成交恢复、空数据、未来时间、连接状态优先级及非时间排序的成交集合。
- 相关 ESLint、TypeScript 检查及 Production build 通过，git diff --check 通过。
- 电脑操控发行版真实旧成交显示“60 秒无新成交”，原列表保留；证据 output/user-audit-20260907/evidence/fix-F08b-final.png/.txt。早期 fix-F08b-quiet 截图使用末尾成交时间，最终版本改用最大成交时间。
- 日志 output/user-audit-20260907/fix-F08b-tests.log、fix-F08b-typecheck.log、fix-F08b-build.log。

60 秒是展示阈值，不是交易所断流判定，也不代表本次修复消除了上游延迟。F08 的观测模式措辞和全局连接范围仍待处理。
