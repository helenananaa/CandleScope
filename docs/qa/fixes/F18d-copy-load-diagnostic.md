# F18d：复制图表加载诊断摘要

对应审计 F18 的可复制诊断需求。此前错误详情虽可展开，但缺少集中复制图表上下文与错误的入口。

## 修改

- 加载失败面板增加“复制诊断摘要”，内容包含 CandleScope 故障类别、当前图表交易对、周期和完整原始错误。
- 仅在剪贴板写入成功后显示成功提示。写入被拒绝或 API 不可用时显示失败提示，并提供只读文本框；聚焦文本框可全选后手动复制。
- 错误或图表上下文变化后，不显示旧摘要的成功提示。九种语言均补齐按钮及结果文案。
- 复制操作只写本地剪贴板，不上传日志，不读取账户或浏览历史，也不发起网络诊断。

## 验证

- 3 项针对性测试通过：错误安全文本渲染及复制入口、摘要上下文和多行错误保真、剪贴板拒绝和 API 不可用时返回失败。
- `npm run typecheck`、针对性 ESLint、`git diff --check` 通过。
- `npm run build` 成功。在隔离端口 15176 使用同一生产 dist，通过模拟 K 线 HTTP 503 重现失败面板；主后端保持运行。
- 通过电脑操控点击复制，看到成功反馈；粘贴到 Chrome 页内查找框，确认内容含 BTCUSDT、1h 和 `QA simulated failure: DataManager not initialized`。
- 截图及 AX 证据：`output/user-audit-20260907/evidence/F18d-copied.*`、`F18d-pasted-summary.*`。构建和类型检查日志在同一输出目录的 `F18d-*.log`。

## 边界

复制失败通过函数测试覆盖，未修改浏览器权限来实测手动复制文本框。生产构建测试在 Chrome 中进行，不代表原生安装包验证。此摘要用于图表加载错误，不声称自动包含网络检测结果或数据引擎健康状态；这些状态由 F18c 的独立诊断提供。
