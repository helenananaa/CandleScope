# 商品选择：跨来源查询与筛选

2026-09-21，第一、二阶段实现及本地验收。

## 行为

- 默认查询所有已收录来源，可按商品代码、名称、交易场所搜索；“全部 / 最近使用 / 收藏”跨来源工作。
- 资产类别、数据来源、交易场所、市场类型和计价币分别筛选。切换资产或来源会清除不适用的旧筛选。
- 来源面板支持名称 / ID 搜索、收藏、最近使用和键盘选择。不可路由来源仍禁用。
- 同商品相邻分组展示来源数量，每一来源仍是独立可选项；股票不同场所、合约到期日 / 行权价、复权 / 时段 / 成交量语义不会因为代码相似而合并。选择传递完整系列身份。
- 默认展示 100 条结果，分页带结果版本；目录变化会重新查询，避免拼接不同版本。输入防抖 250ms；旧请求取消，迟到结果不会覆盖当前筛选。
- 来源覆盖可展开查看：可用、缓存待更新、未加载、需关键词、不可用、限流、超时等。部分目录不被当作全部结果。

## 目录策略

`POST /api/v1/symbols/search` 查询已有主机目录。应用生命周期后台逐个补齐公开来源，优先主要来源，随后包含 lazy CCXT 来源；每 300 秒重扫注册表，接入新插件后无需修改来源列表。复用原有磁盘快照、刷新 singleflight、TTL、失败保留及限流；目录上游调用全局最多 2 个、单次 30 秒超时，后台遇到前台工作让行。查询型供应商不参与全目录扫描。页面已移除手动加载来源入口，准备期间自动刷新首批结果。

查询型供应商只在有关键词时调用。全局最多查询 3 个此类供应商，未查询来源有明确状态并可单独选择。供应商请求共享并发上限 3、5 秒超时、同查询 singleflight、成功缓存 60 秒 / 失败缓存 10 秒；全局最多 24 个等待中的查询、128 个缓存项。供应商结果达到 120 条时提示细化关键词，不冒充完整结果。

最近使用和收藏的键保存于浏览器。供应商已发现的商品元数据按完整系列身份保存于目录快照旁的 `symbol_discovery.providers.sqlite3`，最多 3000 条，重启恢复。新关键词查询成功时只使用当前返回的记录；失败时可以回退已知记录并保留失败状态。首次从未发现的供应商商品仍需实际查询。

中英文及中文变体文案完整；其他语言的新发现功能文案目前使用明确的英文回退，已有来源选择文案保留原翻译。所有 30 个语言目录通过键完整性检查。

## 直接输入快速搜索

- 行情页面未处于编辑或其他弹窗时，直接按英文字母或数字打开商品搜索，首字符带入；Shift 大写和数字键盘的数字同样支持。原有 Ctrl/Cmd+K 和 `/` 保留。
- 首次懒加载期间暂存连续输入，支持退格和 Escape 取消；输入框挂载后立即获得焦点，不再延迟清空首字符。Ctrl/Cmd/Alt 组合键、已处理事件、输入法组合输入、文本编辑、下拉框和其他可见弹窗不触发直接输入搜索。
- 选品单元测试 17 项通过，类型和定向 ESLint 通过。Playwright 真实页面验证 `BTC123`（人为延迟模块加载 600ms）、`600519`、`eth` 完整输入，以及五类编辑区域、其他弹窗、已处理按键、IME、Ctrl+K 和 `/`。
