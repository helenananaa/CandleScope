# F16 纯图导出缺少交易对、周期和指标说明

问题：图表导出直接保存画布，画布外的交易对标题和指标标签丢失；默认关闭的水印不能代替必要的图表信息。

修复：新增独立的“保留图表信息”选项，默认开启（已有导出偏好缺少此字段时同样开启）。在成图上方增加信息区，显示交易所、市场类型、交易对、周期以及可见指标名称和基础参数。信息区占用新增高度，不覆盖原始图形；优先按单词换行，超长连续内容按字符换行。主窗格范围只列出具有可见主图曲线的指标。整页导出保留页面原有信息，不重复增加信息区。水印仍独立控制。

实时图表与本地策略研究图表均接入指标配置。预览缓存身份包含信息开关和指标说明，参数变化后不会沿用旧说明；新增高度纳入导出像素上限检查。九种语言补齐选项文案。

验证：

- 14 项导出相关测试通过：内容身份、可见性与范围过滤、默认偏好迁移、预览失效、长文本换行、裁切、格式及页面冻结。
- TypeScript、相关 ESLint、生产构建、git diff --check 通过。构建仍有原有的大 chunk 提示。
- 通过电脑操控在生产预览 `127.0.0.1:15173` 验证双图窄图格：水印关闭，默认 PNG 成图包含 BTC-USDT-SWAP、15m、MA/MACD/RSI 参数；实际保存并检查图片。最终图片 765×1595；关闭信息后为 765×1295，原图未被信息覆盖。
- 主窗格预览只显示 MA 说明，未列 MACD/RSI，并实际保存。关闭后重新打开面板，信息开关仍保持开启。
- 页面范围回归生成 2400×1616 预览，没有重复信息区，导出对话框未进入图片。
