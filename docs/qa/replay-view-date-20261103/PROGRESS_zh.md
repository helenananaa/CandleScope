## 保留的失败和修正

`full-window-before-fix.log.gz` 保存真实失败：旧页合并到满窗口后，新目标被 newest 裁剪规则丢掉；当前日期读取改为独立有界替换，回归通过。原生旧包还发现裸 workspace ID 与 `replay:run:workspace` 的注册范围不一致，没有发起目标读取；产品绑定修正后实际 HTTP 和视口通过。

脚本失败单独保留，不算作产品通过：最初 12h 可见窗口已经包含目标，不能证明按需读取；紧凑栏中固定周期按钮被滚动隐藏，最终用实际可见的周期选择器；Chromium 会把 datetime-local 的 `:00` 归一化，最终按原生值格式填入；只读 viewport 命令返回值在 output，snapshot 是组状态；图表接受定位后还须等实际下一帧视口覆盖。最终不强制点击、不替换响应、不绕过就绪条件。静态引入日期对话框 CSS 曾使真实 replay hub 测试模块加载失败，改为现有 replay 对话框相同的 lazy 入口后，完整检查通过。

最终流程恢复同一已停止的自有夹具运行，先通过正常布局动作关闭上一尝试留下的额外图，再重建测试分图。每次准备推进均在读取比较基准之前；旧回执按 attempt 子目录保留，原始 profile/数据库/签名包保留在 output，未打包进证据目录。`picker` 候选只组装未启动；不计作验收。
