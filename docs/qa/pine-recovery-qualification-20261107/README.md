## macOS 签名候选的原生证据

从已核对的 Pine 候选物理复制，覆盖并编译一个后端生产模块。1072 个源码及 SDK 指纹、164 个构建文件、9 个插件资产和 76 个插件源码核对通过，严格签名通过。沿用原 ASAR 和运行时。实际应用通过公开 Binance BTCUSDT spot 1m 数据显示两种奇偶结果、偏移线、标记和背景，跨过初次观察所要求的分钟边界。盘中计数下降仅在同域的新 generation 且实际线上的快照报告来源重建时通过验证。

独立 QA 资料库用候选内置存储把一根已确认 BAR 收盘从 76034 改为 76186.07。实际 WebSocket 快照以新 generation 发布该价格，并且图表指标面板显示盘中状态已清除。保存原始脚本后完整退出，重启从同一资料库重新显示该指标，采集到 13 个一致的盘中结果。

**重启后的下一分钟边界仍失败。** 在收到前一根公开最终 BAR 后，指标流返回 `INDICATOR_CALCULATION_ORIGIN_REQUIRED`，停在目标之前，行情来源日志继续接收并确认后续 BAR。维持原跨分钟条件，保留失败记录。两次 sidecar 正常退出，无信号及强制终止，20 条应用拥有的进程记录确认已退出。首轮脚本使用了错误的 QA 数据库文件名，次轮确认了线上的修订价，但界面定位点进设置，第三轮的界面提示和后续失败分开记录。
