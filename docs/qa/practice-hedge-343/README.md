## 复现

在仓库根目录运行。将本地构建的 macOS 包放在新验收目录的 `Installed App/CandleScope.app`，也可以使用符号链接。驱动使用打包的 Python 写入该独立目录中的受控数据，使用桌面控件创建模拟账户、切图和下单。独立客户端通过模拟账户 API 开 ETH 仓、记录笔记、撤保护单及读取状态流。复用运行时或更换行情输入后，实际价格会变化；比对使用当次成交记录。

```sh
CANDLESCOPE_BATCH1_QA_ROOT=/absolute/path/to/fresh-candidate \
CANDLESCOPE_PLAYWRIGHT_PACKAGE=/absolute/path/to/playwright-tooling/package.json \
node docs/qa/practice-hedge-343/native.mjs
python3 docs/qa/practice-hedge-343/verify_balance.py /absolute/path/to/fresh-candidate
```

较早运行保留在本地 QA 目录，包括“添加账户”选择器匹配两个按钮、旧“平仓”及设置关闭文案不匹配、旧构建缺少笔记方向等调试记录。上述回执来自修订后的最终包与完整流程。
