## macOS arm64

使用 `npm run desktop:package:dir -- --mac --arm64 --publish never` 构建，
核对产物中的后端和 Pine 入口源码并验证签名。复制到独立安装目录，用全新的
LOCAL_OFFLINE 配置启动三次。包摘要、数据摘要、引擎身份和回放结果见
[原生回执](macos-arm64.json)。

| 场景 | 实际观测 |
| --- | --- |
| 首次启动 | 内置统一包登记并运行。受限图表帧返回五个预期点，拒绝未来 K 线和其他文档的图表身份。 |
| 策略执行 | 导入 600 根 BTCUSDT 1m 固定 K 线。无效脚本失败。有效脚本产生成交、权益序列和图形。用上一批源码及同一锁定引擎重跑已冻结输入，订单、交易、权益、图形、诊断及引擎原始输出逐项一致。 |
| 回放恢复 | 第 60 根保存快照。完全退出并重启后恢复原快照，在新的 Pine 实例推进到第 600 根，结果与原批跑逐项一致。 |
| 变更生命周期 | 用同一引擎构建测试升级包 0.4.1，经管理入口升级并回滚到随包版本。每次更换实际执行实例，拒绝已撤销实例的调用。停用后再次重启，Pine 保持停用，保存的策略结果仍可读。 |

三次完全退出后均检查进程回收和执行目录清理。离线网络守卫记录零次阻断。
