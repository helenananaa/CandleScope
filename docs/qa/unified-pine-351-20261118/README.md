# #351 Pine 迁移验收

Pine 引擎固定为 `pine-compat-runtime 0.3.3+cs.1`，Pine 入口为 0.4.0，SDK 为 0.2.1。
普通桌面构建的旧脚本插件清单仍供 Python 指标使用。Pine 由随包声明的统一归档登记。

源码集成使用三个锁定输入 wheel 驱动真实 Pine。覆盖指标分析、完整输出快照、受限图表调用、
错误后继续执行、策略图形、固定窗口策略回放，以及进程撤销与同摘要恢复。另测 SQLite WAL
源的首次一致性备份和保留原文件。

完整验收还需 Windows 安装版、实时图表与各回放窗口中实际挂载 Pine 的联合检查，
以及其余旧消费者迁移和旧协议退役。两种图表传输的性能需要独立测量。
