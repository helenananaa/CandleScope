# 回放多图联动延迟修复与复测（2026-10-10）

## 问题与修复

回放多图将联动广播放在 `onVisibleRangeChange`，而该回调经过 500 ms 停手防抖。持续拖拽不断重置定时器，其他图只有停手后才更新。原生当前四图开启的是范围联动。实时行情此前使用用户手势事件和 requestAnimationFrame，不经过这条延迟路径。

回放改接 `onUserViewportRangeChange`，与实时行情共用 `useChartViewportLink`：每帧只广播最新视图，保留延迟保存与完整性记录；程序恢复和接收联动不进入用户手势广播。取消仅活动图才能广播的限制，使直接在非活动图滚轮操作也可联动。切换作用域或卸载取消待处理更新。复盘审阅模式仍不广播。
