# Pine 最终 BAR 的本机时间边界

PR #227 产品源 `b4f89faf9e197ae8e71dd5bef74f5feb5f1342a6`。有序 writer 将提前收到的最终 BAR 保留至该时间周期的本机关闭边界，在计算借用和 owner 锁外异步等待。价格匹配、canonical 读取和来源屏障保持有效。等待仍由现有订阅生命周期取消。

真实 ASGI、事件总线、SQLite 和 Pine worker 反例中，原实现提前 250 ms 执行最终 BAR。修复后只在边界执行，盘中计数 502 经收盘 503，再接下一根 504，generation 一致。另两项普通收盘探测保留 1 次和 6 次盘中观测的各自轨迹。45 项专项通过，84 套件组合 1103 项通过、1 项 Windows CRT 专属跳过、5 项警告。

## macOS 实际公开行情

同一基础签名应用上叠加三个诊断点，短版与延长版各完整走完受控来源修订、显示提示、保存、退出、重启和跨分钟观察。延长版三个真实最终 BAR 分别提前 280、267、237 ms 到达，均收到来源屏障；完整快照分别提前 42、56、34 ms 提交。

产品修复候选从已验签应用物理复制，仅覆盖并编译一个后端模块。严格签名及 1072 源码/SDK、164 构建、9 插件资产和 76 插件源码核对通过。签名应用通过延长版观察，重启后见到 68 个一致的盘中结果和三个最终 BAR。三个最终 BAR 分别提前 296、334、330 ms 到达，相关快照在本机边界后 171、177、166 ms 提交。三次在边界前仍返回来源变化并重建 generation，盘中计数连续性仍待解决。此前稍晚到达的 `INDICATOR_CALCULATION_ORIGIN_REQUIRED` 在本轮未复现，原失败资料继续保留。原生前后两次 sidecar 正常退出，应用拥有进程均已独立检查。
