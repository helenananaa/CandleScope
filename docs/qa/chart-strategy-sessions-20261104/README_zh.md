每检查点64MiB、每运行128MiB/8点、全部默认512MiB；初始精确重试receipt和最新恢复点保留，不清除其他运行以腾空间。达到预算拒绝事务并保留原账户与游标。服务必须按批次/恢复边界调用，不能逐tick全量保存；IO失败后按最后提交点重载再恢复。未知数据库或版本拒绝覆盖。
