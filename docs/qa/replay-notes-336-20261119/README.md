## 构建与复现

使用 Electron 43.3.0、当前前端生产构建、当前后端和控制适配器，沿用本机已有的 Python 与插件运行时。1,160 个源码、SDK 和桌面文件以及 170 个构建产物与包内对应文件匹配。运行前后的深度签名校验通过。Windows 安装版另行验证。

构建桌面包后，将它放在新验收目录的 `Installed App/CandleScope.app`，也可使用指向该包的符号链接。在仓库根目录执行以下命令，其中第二个路径指向已安装 `playwright-core` 的工具项目。驱动通过本地正式 API 准备数据和四个笔记上下文，通过桌面 UI 截图、编辑、制造保存冲突后的恢复和图形复盘。创建运行时复用既有原生回执中的请求模板。

```sh
CANDLESCOPE_BATCH1_QA_ROOT=/absolute/path/to/new-qa-directory \
CANDLESCOPE_PLAYWRIGHT_PACKAGE=/absolute/path/to/tooling/package.json \
node docs/qa/replay-notes-336-20261119/native.mjs
```

本次回归通过 24 项后端笔记测试、685 项正式回放前端测试、39 项轻量回放与历史研究测试。历史版本缺失、截图预算及不确定提交重试由对应的后端与组件测试覆盖。图形复盘上一事件和下一事件的既有安装版证据见 [原生复盘记录](../replay-review-native-main261-20261106/README.md)。
