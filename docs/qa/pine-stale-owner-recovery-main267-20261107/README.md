# Pine 计算状态失效后的实时恢复

产品源 `5e31ef63eea67adc63af1ec1eedd854fa4025a3d`，main `b442555d582dc0bb473bad92ac5e699efdaa78d5`。受控反例使用真实 HTTP/WS、路由事件总线、SQLite 和 Pine worker。停止 worker 后，缓存读取识别投影丢失。旧行为在下一根已确认 BAR 仍从尾段请求，触发 `INDICATOR_CALCULATION_ORIGIN_REQUIRED`。修复后实时命令读取 owner 失效标记，从 canonical 原点重建一代，发布计数 501，下一次观察在同一代继续到 502。冷的缓存读取依然先报告投影丢失，正常读取保留原有行为。

架构检查通过，后端 1,134 项通过，另有 1 项 Windows CRT 专属跳过。

## macOS arm64 实际行情

在同一基线补了查询、owner 准入及 worker 回执三个诊断点。诊断版的公开行情重启轮通过，未复现上一轮偶发错误。修复版完成保存、两次正常完整退出和一次重启，重启后观测到 73 个一致结果，核对到 3 次有序收盘。本轮复验与离线反例分别提供证据，上一轮实盘错误的根因仍未确认。
