# Pine 兼容订阅的写入权与重连

源码 `abe09f4bcdb7f7e9fe11f3ec3f135bf33ed7c65b`，基线 main `b442555d582dc0bb473bad92ac5e699efdaa78d5`。同一 Pine 快照会话的持久身份沿用已有订阅 ID 和标的组合。每个会话只允许一条连接推进。第二条连接若复用仍在使用的 ID，收到 `INDICATOR_SNAPSHOT_WRITER_BUSY`，且不调用 Pine。生产图表为独立会话分配各自的订阅 ID。遇到旧连接仍在清理的情况，前端复用原有订阅确认重试预算。

真实 HTTP、WebSocket、DataManager、SQLite、行情事件总线及固定 Pine worker 验证了并行运行和重连。独立会话在同一盘中事件上分别得到 503 和 501。原连接退出后，同一 ID 重连得到 504。故障测试在旧计算运行时排入下一条已确认事件，确认即使后继任务被取消，旧计算彻底退出前写入权仍保留。

后端组合 1,140 项通过，1 项 Windows 专属用例跳过。架构检查、38 项前端重点测试、TypeScript 和相关 ESLint 检查均通过。最初的扩展回归有 4 项测试替身缺少新增写入权接口，替身改为调用生产接口后，区间规范化套件 20 项通过，并复跑后端组合。独立的全仓库收集尝试需要额外的 `jsonschema` 和本地扩展构建。

旧缺陷的复现对应 [修复前源码](../pine-compatibility-main267-20261107/README.md)。本轮覆盖兼容传输和组件，签名安装包的发布开关与回滚仍需验收。
