# #351 多图和回放插件上下文

本批从实时图、轻量回放、历史研习、正式回放、正式回放复盘和策略结果回放挂载
统一图表 scope。各入口直接消费对应界面所用的已揭示行情投影。显示旧图或仍在
准备新投影时不公开新 scope。已关闭或被回放遮住的实时图不会继续供统一插件选取。
本批最初保留了旧平台的实时图表接口供当时的消费者使用。后续退役批次在应用启动时
关闭旧平台执行。迁移及回滚证据见[旧协议退役的安装版回执](../unified-marketplace-migration-351-20261118/README.md)。

Chrome 生产构建测试了真实 QuickReplayOverlay 的切粒度和回退。1m 行情未就绪时，
插件只收到已揭示的闭合前缀，5m 高价没有被当作 1m 输入。1m 行情到齐后，插件
收到以细粒度数据重建且未收盘的最后一根。回退后故意送到的旧计算结果被拒绝。

后端受保护的 HTTP 测试使用真实的 Python 后端入口和 JSONL sidecar，逐一发送全部
六种模式的绑定范围，并验证跨窗口、超可见时间输入、超出输入轴的结果、
绕开计算回执的发布和客户端断开的取消。前端单元测试验证同一窗口的两张图、
不同窗口中的同名图、回到旧游标及同 ID 图表重挂载不会串结果。

本批通过 243 项 SDK、91 项相关后端和 889 项相关前端测试。通过 TypeScript、
前端架构、插件边界、i18n、变更文件 lint 和生产构建检查。Chrome 验证覆盖轻量回放的
真实挂载。Pine 的安装版恢复和拒绝跨图、越过可见时间的回执见
[原生 Pine 验收](../unified-pine-351-20261118/README.md)。
各图表模式逐窗挂载及其关闭后的安装版联验仍由 #351 跟进。

复现入口为后端 `pytest -q tests/test_unified_chart_context.py` 与前端
`node scripts/frontend-script-integration.mjs --quick-replay-step`。
