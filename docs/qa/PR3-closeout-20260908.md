## 范围与修复

基线为 PR #3 合并提交 `1e01124e`。本次在 Windows x64 使用锁文件依赖、Vite production、Electron 43.3.0 和包内 Python 3.12.14 验证，QA 用户目录与现有用户数据隔离。

- 打包补齐 `pyarrow==21.0.0`，使默认开启的本地回放归档功能在独立成品内可用；干净依赖安装未下载 Electron 时，打包器按锁定版本获取运行时。
- 通过父子进程私有管道正常关闭后端；Windows 先检查管道可读性，避免阻塞读导致 NumPy DLL 初始化停滞。启动中退出也完成生命周期清理。解释器缺失转换为可见错误并释放资源。

- 策略页健康检查使用实际后端地址；共享盈亏颜色在独立策略页的明暗主题均可用。
- 下单可抢占后台额度预览，仍须通过新的同游标额度和订单预览校验；控制命令和重复提交保护保留。验收输入也尊重 `aria-disabled`，不会重试已发出的点击。
- 搜索的自选菜单只因自身弹窗滚动、外部点击或窗口尺寸变化而关闭，后台盘口滚动不再使菜单消失。移除过时的垂直滑块 CSS。
- 盲化模式仅保留安全的目录版本重试信号，仍屏蔽日期、文件路径和其他数据细节；跨校验窗口的目录变化可刷新重试，冻结起点保持不变。
- 验收脚本同步当前文案、语言无关的 K 线计数、显式 HEDGE 配置与离线商品元数据，并在进程网络层强制仅允许回环连接。Windows 沙箱实测现场生成有效期内的签名索引，保留产品过期校验。
- 当前插件验收快照仅更新新增 SDK 示例带来的包摘要及已审阅 UI 摘要；历史 v1 快照不变，协议、权限、沙箱和默认授权字段不变。配置测试使用独立 `.env`，恢复测试等待明确结束状态而非固定次数空轮询。

## 原生成品流程

- 限制 PATH 为系统目录，移除外部 Python、后端命令和数据目录覆盖；只指定独立 QA userData 与测试端口。迁移到带空格的独立成品目录后启动成功。
- 原生行情加载 1,501 根历史 K 线和实时盘口；EMA20、RSI14 可见，1h / 15m 往返正常。
- 真实下载 BTC 1m 历史后，将 2,880 根连续 K 线写入不可变回放归档；从原生页面创建训练、选择商品并推进，显示 200 → 201 根，序列和修订递增。
- 导入 1,500 根官方历史 CSV，运行 SMA 模板，报告、成交与结果面板完成，刷新和重启恢复数据、脚本及结果。数值仅作功能验收，不作策略表现结论。
- 创建线段并跨页面、重启恢复。BTC/ETH/SOL 自选添加、原生 HTML5 拖动、按当前报价升降序排序以及重启保存通过。
- 单窗口四图（1h、15m、4h、1d）均加载 K 线和指标。未以单显示器验证替代四物理显示器验收。
- 原生另存为实际生成 2,536 × 1,480 PNG，覆盖四图与可见页面；浏览器调试连接的下载事件不足以替代该原生对话框操作。
- `REPLAY_ENABLED=0` 时入口不可用，四图保留，回放数据库 SHA-256 不变；恢复默认后原训练仍为 PAUSED。
- 正常退出出现所有组件及 `Application shutdown complete` 日志，监听端口释放；缺失解释器故障有错误原因和日志路径，确认后无残留。三份业务 SQLite 均通过 `quick_check`。

## 数据与证据

官方 BAR 样本采用 Binance Vision 2026-08 BTCUSDT、ETHUSDT 1m 月度归档，各 44,640 行；官方 CHECKSUM 均匹配，微秒时间戳精确转为毫秒并检查逐分钟连续性。`official-bar-sources.json` 记录来源和摘要。正式验收同时校验这些真实 BAR 样本，但 HEDGE 主交易/恢复场景使用独立的确定性市场、盘口、规则及私有状态模拟夹具。其固定归档保真度标签不表示整场压力运行采用真实市场历史，也不表示真实交易所私有账户历史。

原始日志、截图、官方样本数据库、QA 用户目录与工具运行结果已归档到主工作区 `output/playwright/pr3-closeout/`；关键文件 SHA-256 见机器可读记录。不把行情数据库、QA 用户目录、安装包或临时工具提交到 Git。
