# 图表连续策略三种模式与前端所有者

基于 Draft #253。修改源码与新增测试的 SHA256 清单见 `source-manifest.json`。

## 行为与边界

图表 SDK 策略测试器新增纯历史、历史接实时、纯实时三种运行模式，并保存模式偏好。纯历史继续使用已有固定历史流程；两种连续模式直接采用当前 SDK Python 编辑器代码、参数、输出类型及明确输入的账户/费率设置，不要求创建或选择用户策略版本。

连续模式目前限原生加密市场 UTC 1 分钟 K 线、现货现金或 Binance 线性 V1 账户、杠杆 1 倍、资金费关闭。未经当前代码本地授权或不在资格范围内，禁用初始化；Pine、原生 Python 的另一引擎或其他语言不被重标成 SDK Python。源代码修改后须明确新建独立运行，旧账户可从保存列表重新观察或停止。研究结果回送图表的完整工作流仍待实现。

初始化前先保存稳定请求键；请求结果不确定时，按相同键查回或重新提交，后端维持幂等。每个请求独立留存恢复引用，再更新当前选择指针，防止切换账户或多个视图覆盖请求键。引用包含原账户编号、创建时间、输入摘要和账户设置，不复制源代码或账户历史。按完整图表/草稿/模式/市场语义隔离；最多保留 64 条选择指针与请求引用，容量不足明确失败，不删除旧记录。后续新读取者恢复设置和原账户；这属于浏览器存储/组件证据，原生整进程保存退出重启尚待验收。

## 数据通路和预算

页面仅调用工作区 MarketDataManager.strategy.continuous；HTTP/WS 传输通过 StrategyDataManager 创建和销毁。固定历史与连续操作共享原 32 个外部操作预算。连续结果与实时 K 线缓存隔离，同一运行的多个观察者共享一个 HTTP 初始化与一条 socket；最多 32 个观察者、4 个结果视图。最后观察者退出只释放视图，不向后端发送停止。

先读取控制摘要，让恢复中的初始计算可以暂停；随后通过 HTTP 等待并分页获取初始结果，整组封存后才用完整提交 identity 连接 WebSocket。HTTP 分页冲突丢弃未完成组后有限重读。增量按 begin/complete 暂存变化行，只有完整组才发布；断线或 reset 保留上一份完整结果，未完成组不泄露到显示。元数据与已接受的新行冻结，消费者不能修改财务显示记录。

每个结果视图以编码行大小加固定开销计费，已提交行与暂存行合计默认不超过 16 MiB，四视图合计 64 MiB 行预算。这是序列化数据预算，不是实测 JavaScript 堆上限。HTTP/WS 单包 1 MiB，每页最多 200 条，HTTP 初始化最多 2048 页；达到限制显式报错，后台账户继续保存。界面仅取最近 100 条成交和 200 个权益采样点，明确标注范围。提交增量不复制完整历史，输入代码摘要仅在输入变化时重算。

连接开启超时 30 秒，心跳超时 90 秒；连续失败最多重连 5 次，退避为 250/500/1000/2000/4000 毫秒。只有真实服务事件能重置失败预算，socket 刚打开就断开不能无限重试。运行停止、准备失败和来源历史修订均可见；REPAIR_REQUIRED 保留旧结果并标过期，未提供或暗中执行修复。

简体中文、英文、日文、韩文、巴西葡萄牙文新增完整域文案；其余已有语言暂使用英文域文案。各语言键数、占位符和现有语言质量门槛仍保留。
