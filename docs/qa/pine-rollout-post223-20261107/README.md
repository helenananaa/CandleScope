# Pine 图表启动切换和回滚

源码 `51bf8dfc8e2fc55e1157dd593bde1bcafb55f14c`，基线 main `5f6b4a3edb4198963c1e868bad299ca1c76ddfc2`（已含 #223）。后端回归组合 1,160 项通过、1 项 Windows 专属用例跳过。架构、TypeScript、69 项前端重点测试和 132 项桌面测试通过。

同一份本地签名的 macOS arm64 候选使用同一隔离配置目录，连接实际 Binance BTCUSDT spot 1m。依次启动默认计算模式、显式兼容快照模式、显式计算模式。三次均在真实界面渲染了已保存 Pine 指标，源文件及输入编号 1 的参数值 9 一致。后端健康报告与桌面 preload 的模式逐次一致。

- 默认和恢复计算模式均使用 HTTP 计算域及带引用的 WebSocket。回到计算模式后取得新域。
- 兼容快照模式使用旧 HTTP 范围及显式标记的 WebSocket 订阅。本阶段没有发送创建计算域的请求。
- 在兼容模式提交旧计算引用，得到传输配置不匹配。在再次进入计算模式后提交同一引用，得到计算域不存在。
- 三次完整退出的 sidecar 均以代码 0 退出。退出后应用拥有的进程均已消失，候选签名及来源核对通过。

首轮用例误以参数名称作为键，收到 `PINE_INVALID_PARAMS`。用固定版本编译器取得输入编号后，在新配置目录重跑。首次诊断与正确输入分析均保留。

本证据覆盖签名 macOS 本地候选。发布安装包 CI 和 Windows 桌面独立验收。快照模式仍可使用插件已协商的 IPC 能力。
