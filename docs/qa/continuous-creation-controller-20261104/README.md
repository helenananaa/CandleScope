# 常驻 BAR 创建控制器：本地证据

基于 Draft #247 的创建日志；应用提交 `95203bd7`。本层为私有后端所有者，还没有公开 HTTP/WS、结果投影、界面或默认应用生命周期绑定。

## 行为

- `HISTORY_LIVE`：后端固定首次已收盘 UTC 1m 截止点，Manager 原始数据订阅先于查询；等待 Manager 补齐时由完成/修订事件唤醒。私有封存输入、Provider 准备和同步来源保护通过后，创建财务账户，再由 Runtime 分批初始化并追赶尾部。
- `LIVE_ONLY`：不读取初始化历史，从同样固定的下一根分钟开始。两种模式都保留同一账户和事件游标；同键重试保留原代码、条件、账户和截止点。
- 创建一经后台准入，HTTP/视图取消不会取消已接受的任务。独立的暂停、恢复、显式失败重试、终止与应用关闭负责生命周期；初始化前的修订最多自动重新封存三次，已有财务结果的修订继续进入 `REPAIR_REQUIRED`。
- 一个准备线程，无待排队线程任务；默认两个运行 Actor。准备与 Runtime 订阅交接先取得运行需求，再释放准备需求。重启恢复仅准入容量内任务，其余明确返回 `not_admitted`；容量释放后需显式再次准入，没有无限隐式等待队列。
- 配置目录以操作系统文件锁维持单一所有者。关闭须等实际线程、Provider 和数据需求释放完才关闭 SQLite 与锁；清理失败保留所有权供关闭重试。
- `LOCAL_OFFLINE` 拒绝市场创建、恢复和启动。输入资格仍限 #246 的原生加密市场 UTC 1m / V1 账户、杠杆 1、funding OFF；本 PR 没有扩展语言或市场资格。

## 空间与保存

初始化仅使用带配置目录/数据库归属标记的 `continuous-strategy-inputs` 私有目录，不接管普通本地资料库。默认总输入 512 MiB、单份 128 MiB，保留至少 64 MiB 可用空间；来源 OHLCV 在物化前受字节预算限制，发布后检查实际文件字节。无法确认归属或发现符号链接时拒绝自动回收。

财务定义（含暂停、失败、终止账户）以及待创建 READY/FAILED 输入继续被引用保护；仅收集私有目录内无引用的复制品/中断 staging。准备取消后释放其同一未提交来源实例，清除输入引用，保留有界幂等墓碑。定义累计 64 MiB，墓碑及请求总数最多 `max_runs * 4`，不会通过清空幂等记录放宽预算。终止后的财务记录和初始输入仍保留，未增加删除财务账户的接口。

## 验证

- `controller-fourth.log.gz`：16 项控制器场景通过，5 条既有提示。包含 builtin/Python × 两种模式，补齐事件唤醒、请求取消后继续、暂停/恢复/取消、复制中重复取消关闭、锁归属、磁盘超限后显式重试、修订前后边界、清理失败后重试，以及账户已提交但 Actor 尚未启动的重启窗口。
- 其中一个实际全新后端进程从持久化 Python 源码重建 Provider：20 → 25 根，账户 ID 不变、代际增加、原成交前缀一致，关闭后需求与 Provider 临时目录释放。
- `controller-full.log.gz`：相关策略、来源保护、财务状态、进程/线程、Manager、应用关闭、历史账户回归共 **290 passed / 5 warnings / 0 skipped**。不是全仓库测试。
- 架构检查返回既有 10 条，与原 main 基线逐字节相同，并未宣称检查全绿。见 `controller-architecture.log.gz`。
- 第一轮 9 通过/1 失败：错误要求纯实时仅 5 根时必有成交，修正测试断言；第三轮 14 通过/1 失败：错误要求初始窗口观察必须等到后续实时追赶结束，改为分别验证原窗口已提交和后续达到 25 根。原失败日志保留，未放宽来源或财务合同。
