# 长历史 Pine 图表计算

产品源码 `e6768b3bacd4049bca638385a80c101cb24ce2bc`，main `b442555d582dc0bb473bad92ac5e699efdaa78d5`。Pine 仍使用既有脚本预算，DataManager 每次最多读取 10,000 根。长窗口按交易日历拆成无重叠的有序页面，短窗口保留单次读取。每页都核对持久化版本，允许尚未读到的页面物化数据。已读页面如被修订，整次请求拒绝发布。最后一次发布仍受原来源凭证保护。

真实 ASGI、事件总线、SQLite 与固定 Pine worker 测试覆盖 12,001 根的首次初始化和原点重建、两页之间修订第一页面、中间缺一根。两个失败路径均不执行 Pine。后端 1,138 项及架构检查通过，另有 1 项 Windows CRT 用例跳过。
