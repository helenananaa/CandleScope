# P-H01b：后端原生函数采样

基线 `8d697866`，后端 PID 24627，无 reload；Chrome production dist。双图 OKX BTC-USDT-SWAP，MA/MACD/RSI，保留资金费率与持仓量及市场侧栏。

用 macOS `/usr/bin/sample` 对已核实监听 18080 的后端作只读采样：静置 5 秒、间隔 10 ms；随后 15 秒采样窗口内通过电脑操控切换 1m→15m→3m→15m。窗口包含截图与操作等待，不是持续高频交互；原报告的 ETHUSDT 手动历史扩展场景并未被此次完全复刻。

| 项目 | 静置 | 周期切换窗口 |
|---|---:|---:|
| 主线程样本数 | 448 | 1354 |

线程等待栈占多数。交互窗口还可见 gc_collect_main 46、visit_decref 37、dict_traverse 31 等顶栈样本。不同窗口时长、全线程采样及调用栈归并意味着这些数值不能直接比较为 CPU 百分比，也不能算作 FPS/输入延迟。

目前证据说明交互包含 Python 执行、分配与回收活动，并不定位具体业务函数。Physical footprint 不是原报告 ps RSS；本次不是相同数据与负载，不应把较低数值宣称为优化收益或否定原峰值。现有结果不支持内存泄漏结论。

下一步需要 Python 级函数名和受控窗口剖析，区分数据查询、指标计算、缓存合并与序列化；在得到证据前不改缓存、节流或 GC 设置。本次没有业务修改或修复提交。
