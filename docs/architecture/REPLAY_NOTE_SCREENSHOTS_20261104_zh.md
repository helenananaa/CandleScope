# 正式回放笔记截图执行边界

承接#237（源码cb20e41c，依赖#235/#236），对应#166的版本截图子范围。本文件是实现约束，不是资格证明。

- 所有权：沿用双Manager、TrainingRunService serialized与ReplaySQLiteStore注释事务。PNG作为不可变、运行/轨道/数据版本所属的注释资产；每张最多2MiB，每运行最多16MiB/128张，每个笔记版本最多关联2张。SQLite BLOB避免额外路径或跨库账户，不写行情缓存或金融表。
- 截图：复用现有renderExportImage的同步canvas固定和drawing export lease。增加只读source receipt，使用SingleChartPanes已存在paintedSourceRef核对当前store/版本；仅在暂停/结束、当前活动图和投影已准备时捕获，两个绘制帧后核对，捕获前后全视图上下文与源版本变化均拒绝。图表像素已经固定后才异步编码。不得绕过Review/public-time/源揭示边界。
- 两阶段：先上传不可变PNG（独立client ID，结果不确定可按原始请求重试），再由文字版本在同一注释事务绑定已持久化图。前端字符串表单字段replayScreenshotIds使原JournalEditor保存、队列、草稿及重试继续适用；图片不塞进文字字段或放大普通文字请求上限。
- 草稿：捕获后先持久化待提交PNG请求并在文字草稿中保留待处理ID；上传成功且关联草稿保存后才释放本地待提交副本。重新打开可重试原请求或读取已经落库的同ID记录。原上下文过期未提交时保留素材，显式另存才复制到新请求，保留原图片请求及草稿；不会静默重绑定。
- 时间：PNG记录当时捕获上下文及实际保存时间，后来显式复制可保留原捕获时间。上传/关联仅允许同运行、轨道和数据版本，捕获市场时间与事件序号不得超过当前视图。新图片只能进入新笔记版本，旧版不会追加后来图片。读图片必须通过可见的具体笔记版本，回退同毫秒更早事件亦不能取到未来PNG。
- 恢复与预算：资产先提交但未绑定时仍保留，受预算约束，可供明确重新选择；不会按“孤儿”推测删除可能属于草稿的数据。删除运行由既有FK级联清理。保存或上传失败保留正文/选择和待提交素材，不能以当前图替代原素材。
