## 协议和产品边界

1. 显式白名单复用 UI/领域动作。没有任意 JavaScript 求值、主机路径访问、凭证录入或系统操作工具。插件声明的命令继续经过插件平台权限和参数检查。
2. 写操作需要 requestId 与当前 contextToken；窗口、输入和对象状态冲突会拒绝。普通操作串行，明确取消可中断。异步结果仍需查询 error/job/state，applied 仅表示入口确认。
3. 文件有 SHA256/长度验证、窗口绑定、32 KiB 分块、32 MiB 单文件、128 MiB 总量、64 个引用和 30 分钟闲置过期。重载/关闭清除。UI 允许更大文件时使用原流程，文件大小并不完全等价。
4. 系统通知权限、浏览器用户手势、外部地址和已有权限仍由平台处理。MCP 不能强行获得系统权限。回放与实盘分属不同命令及授权。
5. 本次补齐上述功能入口，尚未逐项验收所有菜单、视觉手势、功能开关组合与真实后端的产品等价性。新增 UI 功能必须同步增加显式控制契约。
